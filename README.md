# Doctor Binder v2.1

Скрипт для AutoHotkey **v2** — биндер для медицинской RP-игры (SAMP GTA).

## Запуск

Запустите **`google.ahk`** (правой кнопкой → *Run Script*, или через установленный
AutoHotkey v2). Все остальные файлы подключаются к нему автоматически.

## Структура (разбит на модули)

```
google.ahk                 ← ГЛАВНЫЙ файл: настройки, хоткеи, запуск
lib\
  01_Constants.ahk         ← константы (версия, лимиты, пути)
  02_Globals.ahk           ← все глобальные переменные
  03_UI.ahk                ← кнопки, ховер-эффекты, тёмная тема
  04_Utils.ahk             ← вспомогательные функции
  05_Notify.ahk            ← всплывающие уведомления
  06_Filters.ahk           ← фильтры биндов
  07_Profiles.ahk          ← загрузка/сохранение профилей
  08_Overlay.ahk           ← внутриигровой оверлей
  09_Chat.ahk              ← слежение за чатом, СМС, упоминания
  10_MainGui.ahk           ← главное окно
  11_BindList.ahk          ← список биндов, захват клавиш
  12_Editor.ahk            ← редактор бинда
  13_Sending.ahk           ← отправка сообщений, регистрация хоткеев
  14_Settings.ahk          ← сохранение/загрузка настроек
  15_Menus.ahk             ← радиальное меню, выбор бинда
  16_Telegram.ahk          ← статистика запуска в Telegram
```

Модули в `lib\` **не запускаются отдельно** — они подключаются к `google.ahk`
через директиву `#Include`.

## Как это работает

- `google.ahk` — тонкий файл: вверху подключает все модули, внизу — горячие
  клавиши и блок запуска (`LoadConfig()`, `BuildMainGui()` и т.д.).
- Порядок `#Include` не важен для функций (AutoHotkey v2 регистрирует их при
  загрузке скрипта), поэтому функции можно свободно перемещать между модулями.
